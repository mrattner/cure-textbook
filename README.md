# Organic Japanese by Cure Dolly

Built on top of extensive previous work by Mordraug, Nunko, and Kellen, this project is a fork of Cure Dolly's video transcripts, ported from Markdown to TeX.

## Why?

When I first discovered Cure Dolly's videos, I was thrilled to find a version of her Organic Japanese course that was easy to peruse on a web browser. I found myself itching to look up all the cross-references of concepts mentioned in different lessons and note them down. What I really wanted was a fully indexed textbook to follow along while re-listening to her videos, more so than just transcripts.

To support the enhancements I wanted to add, I chose TeX for its flexibility and the convenience of index-building macros. Indexing is a complex task, and I am not trained in library science. I'm merely a language enthusiast who likes to compulsively organise information. This project is mostly an outlet for me to tinker with book formatting and spend more time with the lessons.

### Goals

- Be able to easily generate an ebook from the transcript files
  - Solely due to my own preference for offline reading in .epub format.
- Section the text for easier navigation from a table of contents
- Link recurring concepts to build a topic index
  - I can't say the tags I choose will be any good, or that I'll get anywhere close to tagging all of the text.
- Render Japanese text with kanji and furigana
  - As started by @dominikun in Kellenok/cure-script#8. This is also a rather large endeavour that I don't expect to finish.

This fork diverges significantly from its parent repo in its format and purpose; it isn't intended to be able to merge back upstream. Since I don't know Russian, I'm working with the `en` documents only.
